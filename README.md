# mern reels app
 
### Features
1. Secure Authentication system
2. login via username or email
3. post feature --> user can create , like , comment the post
4. follow and unfollow
5. edit the profile feature


### Future Scope -> FUCNTIONALY to be implemented :-

1. search functionality -> search the user by it's username
2. real time chat with other users present on the application
3. security ke liye token blacklisting and optimization ke liye redis
4. Home feed from followed users. Show posts only from people the user follows, newest first. This is the heart of Instagram, and it lets you talk about database queries and design.
5. Pagination or infinite scroll. Load 10 posts at a time instead of all posts. Interviewers like this because it shows you think about performance.
6. Notifications. For a like, comment, or new follower. If you add real-time updates with Socket.io, that is a big plus.
7. Image upload with cloud storage. Use ImageKit or Cloudinary, not local files. You already used ImageKit in FaceSense, so this should be easy.
